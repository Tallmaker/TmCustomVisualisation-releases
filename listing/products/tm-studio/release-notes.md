## New

First public release: HTML and CSS templates for Qlik Cloud, with 22 chart, card and list types and four infographic briefings. Native, Harbor, Signal and Margin styles work independently of the layout and can follow an app variable. Includes template helpers, selections, tooltips, sheet navigation, paging, an AI prompt and optional author scripts in a sealed frame.

## Changed

The licence key of this product is now `tm-studio`. A licence issued for the earlier product key does not apply to this version; Tallmaker issues a licence for Tm Studio in its place. Until it is in the tenant's licence extension, the object shows the licence attention message; rendering and interaction are never blocked. The release file is now named `tmstudio-<version>.zip`.

## Fixed

None in this release.

## Before you upgrade

Tested on Qlik Cloud with Chrome. Other browsers are not yet tested. Loading a preset replaces saved HTML and CSS; changing Style keeps them. Review scripts before enabling them. Image and PDF export are unsupported. Story snapshot creation works on Qlik Cloud; playback is not yet verified. See [Requirements and limits](docs/good-to-know.md).

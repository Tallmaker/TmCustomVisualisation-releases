## New

First public release: HTML and CSS templates for Qlik Sense, with 22 chart, card and list types and four infographic briefings. Native, Harbor, Signal and Margin styles work independently of the layout and can follow an app variable. Includes template helpers, selections, tooltips, sheet navigation, paging, an AI prompt and optional author scripts in a sealed frame.

None in this release.

## Fixed

None in this release.

## Before you upgrade

Tested on Qlik Cloud with Chrome. Client-managed Qlik Sense and other browsers are not yet tested. Loading a preset replaces saved HTML and CSS; changing Style keeps them. Review scripts before enabling them. Image and PDF export are unsupported. Story snapshot creation works on Qlik Cloud; playback is not yet verified. See [Requirements and limits](docs/good-to-know.md).

# Presets

Seven presets give you a starting template: KPI cards, a ranked list with bars, status tiles, a simple table, an SVG bar chart, a grouped list with group totals, and a blank starter. Each preset uses the same template language, so you can adapt its HTML and CSS to your data.

The listing pictures show the ranked list beside an SVG bar chart, a table beside a grouped list, and KPI cards built from the synthetic showcase data.

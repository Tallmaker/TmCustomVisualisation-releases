# Author scripts

Author scripts are off by default. When enabled, a script runs in a sealed frame that sees only this object's data and cannot reach Qlik or the rest of the sheet or load anything from the network. A script can still pass on the data it is given, so use only scripts you trust.

Author scripts run on Qlik Cloud; other Qlik sites and browsers are not yet tested. When a site blocks scripts, the template shows without the script.

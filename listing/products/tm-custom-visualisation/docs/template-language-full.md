# Template language

Generated by `node scripts/template-docs.mjs --write` from the helper registry and the render policy. Do not edit by hand.

Tm Custom Visualisation renders the HTML and CSS in the Template section of the property panel. Tags in double braces put the data into the markup.

## Where the template comes from

"Template source" picks the HTML and CSS fields, or two expressions. With expressions, for example `=vTemplateHtml` and `=vTemplateCss`, one master template in a variable can drive many objects and apps; Qlik evaluates them, so a change to the variable changes every object that uses it.

## Values

- `{{Sales}}` prints the value of a field in the current row, formatted by Qlik. Use `{{[Field name]}}` for a name with spaces.
- `{{col 2}}` is the field at position 2: dimensions first, then measures. Presets use it, so they work with any field names.
- Every value is escaped, so data can never add markup or code. `{{{Field}}}` prints a value unescaped; the safety filter still runs on it.
- Outside a row loop, a field means the first row.
- Brackets nest helpers: `{{round (pct Sales) 1}}`.

## Blocks

| Block                                    | Meaning                                                                                                                                    |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `{{#each rows}} … {{else}} … {{/each}}`  | Repeats per row; the else part shows when there are no rows. `@index` (position on the page), `@number` (row number), `@first`, `@last`.   |
| `{{#each columns}} … {{/each}}`          | Repeats per field: `@column` (label), `@kind` (dimension or measure), `@number`.                                                           |
| `{{#if value}} … {{else}} … {{/if}}`     | Shows a part when the value is true, a non-zero number or non-empty text.                                                                  |
| `{{#unless value}} … {{/unless}}`        | The opposite of if.                                                                                                                        |
| `{{#group rows by Region}} … {{/group}}` | One part per value of a field, in the sort order. `@key`, `@count`; `{{#each rows}}` inside walks the group, and aggregates use the group. |
| `paged`                                  | Add it to one row or group loop, `{{#each rows paged}}`, to show a pager. Set the page size under Data handling.                           |

Data state: `@capped` (not all rows are loaded), `@totalRows`, `@loadedRows`.

## Totals and aggregates

- `total` and `pct` come from Qlik and are always exact.
- `sum`, `avg`, `min`, `max`, `count` and `pct … of group` add up the loaded rows. When not all rows are loaded they stay empty, and edit mode says why. Raise "Maximum rows to load", or add a measure such as `Sum(TOTAL <Region> Sales)`.
- `sum` adds row values. For averages, ratios and distinct counts, use a Qlik measure with TOTAL instead.

## Helpers

### Values

| Helper         | Meaning                                                                                                                                                                                                             | Example                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| `num value`    | The raw number of a value, with "." as the decimal mark and no grouping. Use it for CSS widths and data attributes.                                                                                                 | `<i style="width: {{num Share}}%"></i>` |
| `col position` | The value of the field at a position (1 is the first dimension; measures follow the dimensions). Use it where a template must work with any field names, and wherever a field name is asked for: {{label (col 2)}}. | `{{col 1}}: {{col 2}}`                  |
| `label field`  | The label of a dimension or measure, as set in the property panel.                                                                                                                                                  | `<th>{{label Sales}}</th>`              |
| `state field`  | Whether the current value of a dimension is selected: S selected, O possible, X excluded, A alternative.                                                                                                            | `<li class="state-{{state Region}}">`   |

### Aggregates

| Helper                   | Meaning                                                                                                                                                   | Example                    |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| `total field`            | The grand total of a measure from Qlik. Always exact, also when not all rows are loaded.                                                                  | `{{total Sales}}`          |
| `pct field [of] [scope]` | The current value as a percentage (0 to 100) of the Qlik grand total. "pct Sales of group" uses the current group instead, computed from the loaded rows. | `{{round (pct Sales) 1}}%` |
| `sum field`              | The sum of a column over the loaded rows of the current group, or of all loaded rows. Empty when not all rows are loaded.                                 | `{{sum Sales}}`            |
| `avg field`              | The average of a column over the loaded rows of the current group, or of all loaded rows. Empty when not all rows are loaded.                             | `{{avg Sales}}`            |
| `min field`              | The smallest value of a column in the current group, or in all loaded rows. Empty when not all rows are loaded.                                           | `{{min Sales}}`            |
| `max field`              | The largest value of a column in the current group, or in all loaded rows. Useful for bar widths. Empty when not all rows are loaded.                     | `{{max Sales}}`            |
| `count`                  | The number of rows in the current group, or of all loaded rows. Empty when not all rows are loaded.                                                       | `{{count}} products`       |

### Data

| Helper      | Meaning                                                               | Example                                 |
| ----------- | --------------------------------------------------------------------- | --------------------------------------- |
| `totalRows` | The number of rows in the data in Qlik, also when not all are loaded. | `Showing {{rowCount}} of {{totalRows}}` |
| `rowCount`  | The number of loaded rows.                                            | `Showing {{rowCount}} of {{totalRows}}` |
| `isCapped`  | True when Qlik holds more rows than were loaded.                      | `{{#if isCapped}}Top rows only{{/if}}`  |

### Numbers

| Helper                 | Meaning                                                              | Example                           |
| ---------------------- | -------------------------------------------------------------------- | --------------------------------- |
| `add a b`              | Adds two numbers.                                                    | `{{add Sales Cost}}`              |
| `sub a b`              | Subtracts the second number from the first.                          | `{{sub Sales Cost}}`              |
| `mul a b`              | Multiplies two numbers.                                              | `{{mul (num Share) 100}}`         |
| `div a b`              | Divides the first number by the second. Empty when dividing by zero. | `{{div (num Sales) (max Sales)}}` |
| `round value [digits]` | Rounds a number to a number of decimals (default 0).                 | `{{round (pct Sales) 1}}`         |
| `abs value`            | The number without its sign.                                         | `{{abs (num Change)}}`            |

### Text

| Helper                   | Meaning                                               | Example                              |
| ------------------------ | ----------------------------------------------------- | ------------------------------------ |
| `default value fallback` | The value, or the fallback when the value is empty.   | `{{default Manager "Not assigned"}}` |
| `truncate value length`  | Shortens text to a number of characters and adds "…". | `{{truncate Product 20}}`            |
| `upper value`            | Text in capital letters.                              | `{{upper Region}}`                   |
| `lower value`            | Text in small letters.                                | `{{lower Region}}`                   |

### Logic

| Helper      | Meaning                                                     | Example                                        |
| ----------- | ----------------------------------------------------------- | ---------------------------------------------- |
| `eq a b`    | True when two values are equal. Numbers compare as numbers. | `{{#if (eq Sales 100)}}…{{/if}}`               |
| `ne a b`    | True when two values differ.                                | `{{#if (ne Sales 100)}}…{{/if}}`               |
| `gt a b`    | True when the first value is greater.                       | `{{#if (gt Sales 100)}}…{{/if}}`               |
| `lt a b`    | True when the first value is smaller.                       | `{{#if (lt Sales 100)}}…{{/if}}`               |
| `gte a b`   | True when the first value is greater or equal.              | `{{#if (gte Sales 100)}}…{{/if}}`              |
| `lte a b`   | True when the first value is smaller or equal.              | `{{#if (lte Sales 100)}}…{{/if}}`              |
| `and a b …` | True when all values are true.                              | `{{#if (and (gt Sales 100) (lt Cover 7))}}`    |
| `or a b …`  | True when any value is true.                                | `{{#if (or (eq Status "Late") (lt Cover 7))}}` |
| `not value` | True when the value is false or empty.                      | `{{#if (not isCapped)}}`                       |

### Styling

| Helper            | Meaning                                                                                                 | Example                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| `color index`     | A colour from the app theme palette, 1 to 12, as a CSS value.                                           | `<i style="background: {{color 2}}"></i>` |
| `attr name value` | Writes one HTML attribute with a safely quoted value. Event attributes such as onclick are not allowed. | `<li {{attr "data-region" Region}}>`      |

### Interaction

| Helper            | Meaning                                                                                                       | Example                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| `select field`    | Makes an element select the current value of a dimension in Qlik, with mouse and keyboard.                    | `<li {{select Region}}>{{Region}}</li>` |
| `tooltip value …` | Shows a Qlik-style tooltip on hover and keyboard focus. Each value is one line; a field shows "label: value". | `<li {{tooltip Region Sales}}>`         |

## Selections and tooltips

`{{select Region}}` on an element makes it select that value in Qlik, by mouse and keyboard. The object adds the role, the name, the pressed state and the keyboard path. Style the state with `[data-tm-state="S"]` (selected) and `[data-tm-state="X"]` (excluded).

`{{tooltip Region Sales}}` shows a Qlik-style tooltip on hover and keyboard focus.

## What the safety filter keeps

Tags: `a`, `abbr`, `article`, `aside`, `b`, `blockquote`, `br`, `caption`, `circle`, `code`, `col`, `colgroup`, `dd`, `desc`, `details`, `div`, `dl`, `dt`, `ellipse`, `em`, `figcaption`, `figure`, `footer`, `g`, `h1`, `h2`, `h3`, `h4`, `h5`, `h6`, `header`, `hr`, `i`, `img`, `li`, `line`, `main`, `mark`, `nav`, `ol`, `p`, `path`, `polygon`, `polyline`, `pre`, `rect`, `s`, `section`, `small`, `span`, `strong`, `sub`, `summary`, `sup`, `svg`, `table`, `tbody`, `td`, `text`, `tfoot`, `th`, `thead`, `time`, `title`, `tr`, `tspan`, `u`, `ul`.

Attributes: `alt`, `aria-label`, `aria-hidden`, `aria-describedby`, `aria-labelledby`, `class`, `colspan`, `cx`, `cy`, `d`, `dir`, `fill`, `height`, `headers`, `href`, `id`, `lang`, `points`, `preserveAspectRatio`, `r`, `rel`, `src`, `role`, `rowspan`, `rx`, `ry`, `scope`, `stroke`, `stroke-dasharray`, `stroke-dashoffset`, `stroke-linecap`, `stroke-linejoin`, `stroke-width`, `style`, `tabindex`, `target`, `text-anchor`, `title`, `transform`, `viewBox`, `width`, `x`, `x1`, `x2`, `xmlns`, `y`, `y1`, `y2`, `opacity`, `dominant-baseline`, and `data-*` and `aria-*`.

- No script, no event attributes such as `onclick`, no `javascript:` links.
- Images load from `https:` addresses and from PNG, JPEG, GIF and WebP data. In Qlik Cloud, an image host must be on the tenant's list of allowed sources.
- CSS stays inside the object: `:root`, `html` and `body` mean the object. `@import`, `@font-face`, `position: fixed` and outside `url()` are removed; `z-index` is capped at 10.
- CSS functions kept: `calc()`, `min()`, `max()`, `clamp()`, `round()`, `mod()`, `rem()`, `abs()`, `sign()`, `var()`, `rgb()`, `rgba()`, `hsl()`, `hsla()`, `hwb()`, `lab()`, `lch()`, `oklab()`, `oklch()`, `color()`, `color-mix()`, `linear-gradient()`, `radial-gradient()`, `conic-gradient()`, `repeating-linear-gradient()`, `repeating-radial-gradient()`, `repeating-conic-gradient()`, `translate()`, `translatex()`, `translatey()`, `translatez()`, `translate3d()`, `rotate()`, `rotatex()`, `rotatey()`, `rotatez()`, `rotate3d()`, `scale()`, `scalex()`, `scaley()`, `scalez()`, `scale3d()`, `skew()`, `skewx()`, `skewy()`, `matrix()`, `matrix3d()`, `perspective()`, `cubic-bezier()`, `steps()`, `linear()`, `minmax()`, `repeat()`, `fit-content()`, `blur()`, `brightness()`, `contrast()`, `drop-shadow()`, `grayscale()`, `hue-rotate()`, `invert()`, `opacity()`, `saturate()`, `sepia()`, `counter()`, `counters()`, `inset()`, `circle()`, `ellipse()`, `polygon()`, `path()`, and `url()` with image data.
- In edit mode the object lists what the filter removed.

## Author script

"Run author script" (off by default) adds a Script field. The template still renders and is filtered as usual; the script then runs in a sealed frame that sees only this object's data and cannot reach Qlik, the network, cookies, storage or the rest of the sheet. It cannot open windows, navigate the page or submit forms.

- `tmcv.data`: the rows (`{ Field: { text, num, key } }`), fields, totals and data state; `tmcv.onData(fn)` runs now and on every change.
- `tmcv.select(key)` selects a dimension value, with the `key` of a dimension cell; it works in analysis mode with the object focused. `tmcv.selectionState(key)` gives S, X or O.
- `tmcv.theme`, `tmcv.size` and `tmcv.onResize(fn)`, `tmcv.mode` (analysis, edit or snapshot), `tmcv.announce(text)`, `tmcv.reportError(e)`, `tmcv.root`.
- If the Qlik site does not allow scripts, the object shows the template without the script; edit mode says so.
- A script can still send out the data it was given by reloading its own frame; the object then stops the frame. Turn scripts on only for templates you trust.

## Theme variables

`--tm-fg` (text), `--tm-bg` (background) and `--tm-color-1` to `--tm-color-12` (the theme palette).

## Presets

| Preset                         | Expects                                                                                         |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| KPI cards                      | Measures only, or a dimension and measures. One card per measure, showing its total.            |
| Ranked list with bars          | One dimension, then one measure. Sort the measure descending in the property panel.             |
| Status tiles                   | One dimension, then one measure. Change the two limits (7 and 14) in the HTML to fit your data. |
| Simple table                   | Any dimensions and measures.                                                                    |
| SVG bar chart                  | One dimension, then one measure. Shows how to draw your own marks with SVG.                     |
| Grouped list with group totals | Two dimensions, then one measure. Groups by the first dimension.                                |
| Blank starter                  | Any data. A short commented example to start from.                                              |

## Legacy forms

Templates from the old TmCustomViz extension keep working: `{{hc::Field}}`, `{{hc::row:col}}`, `{{hc::columnName:N}}`, `{{for-rows|hc}} … {{next-row}}`, `{{for-columns|hc}} … {{next-column}}`, `{{currentRow}}`, `{{currentRowNumber}}`, `{{if|A|op|B|yes|no}}` and `{{select|Field}}`. Their values are escaped now too.

Build Qlik views with HTML and CSS or seven presets. Templates show values, repeat rows, use conditions and groups, page data, and format numbers and totals. Values are escaped; HTML and CSS are filtered.

Use selections, keyboard access and tooltips, or source templates from expressions. Data loads in checked pages up to 20,000 rows (5,000 by default); Qlik totals stay exact. Optional scripts run in a sealed frame.

Tested on Qlik Cloud with Chrome. Qlik Sense client-managed is not yet tested. Story snapshots: created on Qlik Cloud; viewing a snapshot in a story is not yet verified. Image and PDF export of this object are not supported in 1.0.0. In a sheet PDF the object may appear blank.
